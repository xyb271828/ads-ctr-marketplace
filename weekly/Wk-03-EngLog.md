# Week 3 engineering log

I built a CTR evaluation pipeline that uses contiguous source windows and preserves the same test rows across every model. Sparse hashed logistic regression establishes the baseline. A second model learns boosted decision-tree leaf features and fits logistic regression on a later portion of training. DeepFM uses embeddings to represent feature interactions, and checkpoint selection uses the validation split. I fitted Platt and isotonic calibration on validation and added a separate negative-downsampling experiment to examine how an altered training prior shifts predicted probabilities.

The marketplace replay is independent of the public benchmark. I kept candidate draws and true click outcomes paired across the auction configurations. Uniform probability inflation should cancel in this reserve-CPC formulation because the price divides the competing score by the winner's probability. The targeted inflation arm changes one contextual segment so it can affect auction dynamics even when global ranking metrics appear similar. The simulation also compares unpaced delivery with a simple feedback policy. I recorded exposure and the time when advertisers lose enough balance to participate.

I exposed a small synthetic ad service for integration with lesson search. It uses only topic and grade rather than a user history. The latency harness distinguishes HTTP response time from prediction and auction time. Model choice on the public dataset depends on held-out LogLoss, normalized entropy, calibration and measured resource costs. On 3,000 held-out synthetic impressions, hashed LR reduced LogLoss from 0.5680 to 0.5300. Negative-prior correction reduced the sampled model's LogLoss from 0.8503 to 0.5365 with unchanged AUC. The real Parquet benchmark used 3.62 million impressions over five separate dates. On 594,104 test impressions, DeepFM lowered LogLoss by 5.31% versus hashed LR. Platt-calibrated hashed LR lowered LogLoss by 4.53% and preserved AUC, making it a useful comparison for a future serving benchmark.

**Resume bullet draft** — Built a contextual ad auction and replay for 50 synthetic advertisers, reducing early budget depletion from 98.7% to 19.3% with pacing and serving the Docker demo at 3.70 ms HTTP p99 over 1,000 requests at 50 QPS.

**Real-data resume bullet draft** — Benchmarked CTR models on 3.62M Criteo ad impressions using day-disjoint splits. DeepFM lowered LogLoss by 5.31% and raised AUC from 0.7369 to 0.7443 versus hashed logistic regression on 594K held-out impressions.
